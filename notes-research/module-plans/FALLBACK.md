# 반려와 병합 계획

폴리트루크 병합본 `ec107c9`에서 분기한다. 원고 5의 국소 수정 1회, 기준 커밋 재구축, 세 번째 실패 격리, 사용자 고위험 경계를 적용한다. 자아비판에 나온 ‘앞선 검증을 다른 후보에 재사용’하는 문제를 막기 위해 두 판정·트리·병합 부모를 모두 확인한다.

- 단일 경미한 BUILD 실패만 같은 후보의 한 차례 수정을 허용한다. 수정 프로세스는 새로 만든다. 구조적 실패는 원본 기준에서 새로 시작하고 판정 코드·짧은 실패 좌표·금지 조건만 전달한다.
- 작업자가 쓸 수 없는 영역에 금지 조건과 유보 상태를 저장한다. 세 번 폐기하거나 미등록 오류·복구 실패가 발생하면 격리한다. 일반 성공, 격리, 검증 실패의 CLI 결과를 구분한다.
- 두 판정이 같은 후보를 가리키면 전용 제안 커밋을 만들고, 통합 브랜치가 실제로 그 트리를 병합했는지 확인한다. 작업 디렉터리에 기존 변경이 있거나 기준이 이동하면 중단한다. 고위험은 후보 지문에 연결한 사용자 승인을 요구한다.
- 시험은 두 번의 재구축과 세 번째 격리, 한 차례만 허용되는 국소 수정, 재시작·중복 실행, 후보가 다른 승인, 다음 태스크 배차를 포함한다. 운영 모델로 만든 작은 덧셈 후보도 같은 경로에서 정산한다. [원고 5](../manuscripts/originals/0005/chat.txt) · [실행 계약](../oracle-scaffold/pipeline.md)
